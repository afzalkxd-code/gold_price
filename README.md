#  Gold Price Prediction using Machine Learning

An end-to-end **Machine Learning** project that predicts gold prices using historical market data. The project covers data preprocessing, exploratory data analysis (EDA), feature correlation, model training with **Random Forest Regressor**, and performance evaluation using Python and Scikit-learn.

##  Project Overview

Gold is one of the most important financial assets, and its price is influenced by multiple economic factors. This project builds a regression model to predict gold prices by analyzing historical market indicators and evaluating the model's prediction accuracy.

##  Objectives

* Import and preprocess historical gold price data
* Perform exploratory data analysis (EDA)
* Analyze feature correlations
* Train a machine learning regression model
* Evaluate prediction accuracy using standard metrics
* Compare actual vs predicted gold prices visually

## Project Workflow

### 1. Data Collection & Processing

* Imported historical gold price dataset
* Explored data structure and feature types
* Checked for missing values and data quality

### 2. Exploratory Data Analysis (EDA)

* Statistical summary of the dataset
* Distribution of numerical features
* Correlation matrix and heatmap
* Positive and negative correlation analysis

### 3. Feature Engineering

* Selected input features and target variable
* Split data into training and testing sets
* Prepared data for machine learning

### 4. Model Training

Implemented the **Random Forest Regressor** to learn relationships between market variables and gold prices.

### 5. Model Evaluation

Evaluated the model using:

* Mean Absolute Error (MAE)
* R² Score
* Actual vs Predicted value comparison
* Prediction visualization
